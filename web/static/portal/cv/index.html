READ BEFORE USE

已知限制

  • 这是整图单标签分类器，不做目标检测或计数；一张图包含多种鱼时不适用。
  • 模型只能在五个已知类别中选择，遇到其他鱼也会尝试给出候选。
  • 训练数据量较小，且主要不是零售冰台现场照片。
  • Kembung 与 Cencaru 是当前最主要的混淆组合。
  • 部分训练图片仍需完成商业许可核查，本版本仅用于 I1 概念验证。
