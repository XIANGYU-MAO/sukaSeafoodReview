SukaSeafood Windows 原图同步工具
================================

1. 在管理后台“训练集同步”页面创建批次并下载任务 CSV。
2. 解压整个 ZIP；不要只复制 exe。
3. 双击 SukaSeafoodTrainingSync\SukaSeafoodTrainingSync.exe。
4. 选择任务 CSV，再选择本地训练集保存目录。
5. API 地址和代理通常不需要修改，直接点击“开始同步”。
6. 下载成功后工具会自动把结果提交给服务器。

如果自动提交失败：
- 训练集目录会出现 download_receipt-批次编号.json。
- 回到管理后台，把这个 JSON 拖到原批次卡片中。

可以重复运行同一份 CSV：已经成功的图片会跳过，失败或中断的项目会继续处理。
网页和中国服务器不保存原图；原图直接下载到你选择的本地训练集目录。
